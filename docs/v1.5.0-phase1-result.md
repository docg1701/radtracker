# Fase 1 — v1.5.0: Resultado da implementação (backend streaming)

## Arquivo alterado

`src/llm_client.py` — único arquivo modificado.

## O que foi feito

### 1. `build_rag_context()` — função pública
- Posição: entre `_USER_PROMPT_TEMPLATE` e `_enrich_stats()`, com separador de seção
- Chama `_enrich_stats()` + `_USER_PROMPT_TEMPLATE` (internos, mesma lógica)
- Aceita `system_prompt` opcional; fallback para `_SYSTEM_PROMPT` padrão
- Retorna string completa com seção `=== DADOS ATUAIS PARA ANÁLISE ===` injetada

### 2. `LLMClient.generate_stream(messages)` — SSE streaming
- Adicionado à classe `LLMClient`, após `generate()`
- Usa `httpx.stream("POST", ...)` com `timeout=30.0`
- Faz yield de tokens linha por linha via `response.iter_lines()`
- Parser: `data: ` → JSON → `choices[0].delta.content`
- Trata `[DONE]` com `.strip()`, JSON inválido, `delta.content` nulo
- Três blocos de exceção: `TimeoutException`, `HTTPStatusError`, `HTTPError` (ConnectError/NetworkError)

### 3. `_build_payload()` — payload builder compartilhado
- Método privado na classe `LLMClient`
- Parâmetro `stream: bool = False`
- Usado por `generate()` (stream=False) e `generate_stream()` (stream=True)
- Centraliza `model`, `max_tokens=800`, `temperature=0.3`

### 4. Refatoração de `generate()`
- Substituído dicionário de payload inline por chamada a `self._build_payload(messages)`
- Construção de `messages` extraída para variável separada (clareza)
- Comportamento **idêntico** ao original

### 5. Imports
- `import json` adicionado (usado pelo parser SSE)
- `Generator` importado de `collections.abc` (ruff UP035)
- `Any` mantido de `typing`

## Decisões de implementação

- `_build_payload()` colocado **antes** de `generate()` na classe (ordem de dependência: init → helpers → public API)
- `build_rag_context()` como função de módulo (não método) — é uma function pura, não precisa de estado da classe
- `import json` no topo do arquivo (não inline) — mais limpo e reutilizável
- `Generator` de `collections.abc` (não `typing`) — conformidade ruff UP035
