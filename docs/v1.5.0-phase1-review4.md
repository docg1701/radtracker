## Fixed (issues found, with location and resolution)

### WARNING — NaN fragility in `_enrich_stats` ma7/ma30 extraction
**Location:** `src/llm_client.py` lines 121–124  
**Issue:** `float(last_row.get("ma7", 0.0) or 0.0)` is unsafe because `np.nan` is truthy. If upstream `compute_historical_stats` ever produces NaN (e.g., `min_periods` param changes), `fmt_brl(np.nan)` crashes with `decimal.InvalidOperation`.  
**Fix:** Replaced with `pd.notna()` guards:
```python
raw_ma7 = last_row.get("ma7", 0.0)
ma7_val = float(raw_ma7) if pd.notna(raw_ma7) else 0.0
```
Same for `ma30_val`.

### NOTE — `_headers()` helper has no docstring
**Location:** `src/llm_client.py` line 347  
**Issue:** R3 introduced `_headers()` to deduplicate header construction. All three reviewers missed the missing docstring on this new function.  
**Fix:** Added minimal docstring: `"Return Authorization + Content-Type headers for OpenRouter."`

### NOTE — `build_rag_context` docstring/behavior mismatch
**Location:** `src/llm_client.py` line 89  
**Issue:** Docstring says "Se None, usa o prompt padrão", but the code does `system_prompt or _SYSTEM_PROMPT`, which also falls back on empty string `""`.  
**Fix:** Updated docstring to read "Se None ou string vazia, usa o prompt padrão (_SYSTEM_PROMPT)."

### WARNING — Missing `test_generate_stream_timeout`
**Location:** `tests/test_llm_client.py` — `TestGenerateStream` class  
**Issue:** The plan v1.5.0 § "Fase 2: Testes — streaming" explicitly lists `test_generate_stream_timeout` as a required test. R3 added 11 tests but skipped this one, leaving the 30s timeout path of `generate_stream()` with zero test coverage.  
**Fix:** Added test that mocks `TimeoutException` and asserts both "Timeout" and "30s" appear in the error message.

### WARNING — Missing `test_llm_client_connect_error` for `generate()`
**Location:** `tests/test_llm_client.py` — `TestLlmClientErrors` class  
**Issue:** R3 added `except httpx.HTTPError` to both `generate()` and `generate_stream()`, but only `generate_stream()` got a `ConnectError` regression test (`test_generate_stream_network_error`). `generate()` had zero coverage for network-level failures (ConnectError, NetworkError, etc.).  
**Fix:** Added `test_llm_client_connect_error` mocking `httpx.ConnectError` and asserting "conexão" in the raised `LLMUnavailableError`.

### NOTE — `test_generate_stream_malformed_sse` used misleading data
**Location:** `tests/test_llm_client.py` line 238  
**Issue:** The test line `data: {"choices":[],"delta":{}}` is **valid JSON with an empty array**, not "malformed" nor "sem choices" (without choices key). The parser's `or [{}]` fallback happens to make the test pass, but it does not actually exercise the "missing choices key" edge case the docstring claims to cover.  
**Fix:** Replaced the empty-choices line with `data: {"delta":{"content":"ignored"}}` (truly missing `choices` key), ensuring the fallback `data.get("choices")` returns `None` and the parser's safe-default path is actually tested.

### NOTE — ruff I001 + F841 in test file
**Location:** `tests/test_llm_client.py` lines 3, 239  
**Issue:** (1) Import block unsorted (`pytest`/`respx` before `httpx`); (2) Unused `route` variable in `test_generate_stream_done_with_whitespace`.  
**Fix:** Sorted imports alphabetically (`httpx`, `pytest`, `respx`); removed the unused `route` assignment.
