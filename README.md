# radtracker

Dashboard pessoal de produtividade para telerradiologia.

## Pré-requisitos

- Python 3.12+
- pip

## Instalação

python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env    # optional — for LLM insights

## Uso

streamlit run app.py

Acesse http://localhost:8501
